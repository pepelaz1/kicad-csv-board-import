# CSV → KiCad: проверенный прототип

Python-скрипт переносит из CSV прямые и дуги дорожек на слои F.Cu и B.Cu, а также круглые неплакированные отверстия. Единицы — миллиметры. Вход проверяется до построения платы; ошибки содержат номер строки.

## Что уже проверено

На KiCad 10.0.8 модуль `pcbnew` создал плату из шести строк тестового CSV. `kicad-cli` экспортировал Gerber для двух медных слоёв и Excellon с двумя отверстиями Ø 1,2 мм. Исходный файл заказчика не использовался: `sample.csv` содержит собственные тестовые данные.

## Запуск

Установите KiCad с [официального сайта](https://www.kicad.org/download/). Используйте Python из его установки либо настройте `PYTHONPATH` так, чтобы был доступен модуль `pcbnew`.

```powershell
python import_board.py sample.csv output/demo.kicad_pcb
kicad-cli pcb export gerbers --layers F.Cu,B.Cu --output output/gerbers/ output/demo.kicad_pcb
kicad-cli pcb export drill --output output/drill/ output/demo.kicad_pcb
```

На Windows `run-demo.cmd` выполняет эти шаги автоматически, если KiCad 10.0 установлен в стандартную папку или в `tools/kicad-10.0.8`. Можно указать свою папку `bin` через переменную `KICAD_BIN`. Дистрибутив KiCad в репозиторий не входит.

`preview.py` строит отдельный SVG-предпросмотр. `test_geometry.py` проверяет разбор CSV и геометрию дуг. Готовая плата и производственный экспорт лежат в `output/`.

## Формат CSV

`line`: слой, начальная и конечная точки, ширина. `arc`: те же поля плюс центр и направление `CW`/`CCW`. `hole`: центр и радиус. Подробный пример — в `sample.csv`.

Прототип показывает импорт геометрии. Для изготовления платы отдельно нужны контур, цепи, правила DRC и проверка производственных требований.
